# mendoza_pavlova

A simple Flutter app showcasing a Strawberry Pavlova recipe page — built as a school activity to practice Flutter layouts and widgets.

### What it does
Displays a clean, responsive recipe card for Strawberry Pavlova with description, star ratings, and quick info tabs (prep time, cook time, servings).

### Built With
- **Flutter 3.13+** / Dart
- Material Design widgets

### Preview
- Header image of Pavlova (`assets/images/Pavlova.jpg`)
- Title & description
- ⭐ 3/5 rating with 90 reviews
- Info row: PREP 25 min | COOK 1 hr | FEEDS 4-6

### Getting Started
```bash
flutter pub get
flutter run
```

### Project Structure
```
lib/
├── main.dart        # App entry point
└── dynamicpage.dart # Pavlova recipe UI

```
